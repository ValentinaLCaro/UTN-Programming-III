## Descripción

Aplicación que permite a los usuarios navegar por un catálogo de productos, filtrarlos por categorías o buscarlos por su nombre, y gestionar un carrito de compras interactivo con persistencia de datos en local storage.

## Funciones implementadas

- **Catálogo Dinámico**: Renderizado de productos desde una suente centralizada.
- **Carrito de compras**:
    - Agregar productos (con incremento de cantidad)
    - Persistencia en ´localStorage´
    - Calculo automático del total
- **Búsqueda y filtros**:
    - Buscador por nombre de producto
    - Menú lateral de categorías con opción "todas"

## Tecnologías utilizadas

- HTML5 / CSS3
- JavaScript / TypeScript
- Vite como entorno de desarrollo

## Instrucciones de ejecución

1. Instalar dependencias con `pnpm install`
2. Levantar el servidor de desarrollo con `pnpm dev`
3. Navegar a la URL indicada (generalmente http://localhost:5173/)
